rclone OAuth client

A private, single-user OAuth client for personal Google Drive access.

What this is

This page exists to satisfy Google's OAuth consent screen requirements for a personal OAuth client. There is no product, service, or sign-up here.

  • It is a single OAuth 2.0 Desktop app client created in Google Cloud Console.
  • It is used by one person, on one privately owned computer, to mount their own Google Drive as a local drive letter using rclone.
  • It is not distributed, not offered to the public, and has no other users.

What it accesses

Only the files in the owner's own Google Drive account, using the https://www.googleapis.com/auth/drive scope. It reads, writes, and deletes files there at the owner's instruction, exactly as the Google Drive web interface would.

Data handling

The OAuth token is stored locally on the owner's computer and is never transmitted to any third party. No analytics, no tracking, no servers of ours are involved. Details are in the privacy policy.
