Privacy policy

For a personal, single-user OAuth client used with rclone. Last updated 19 November 2026.

1. Scope

This policy covers a private OAuth 2.0 client ("the client") created by an individual in Google Cloud Console and used solely to access that individual's own Google Drive account through the open-source program rclone. The client has a single user: its owner. It is not a service offered to anyone else.

2. What data is accessed

The client requests the Google Drive scope https://www.googleapis.com/auth/drive and therefore can read, create, modify, and delete files in the owner's own Google Drive, and read file metadata such as names, sizes, and modification times.

3. How the data is used

Files and metadata are used only to present the owner's Google Drive as a local drive on the owner's own computer, so that the owner can open, save, and manage their own files with ordinary desktop applications. No other use is made of the data.

4. Where data is stored

  • OAuth credentials (access and refresh tokens) are stored locally on the owner's computer, in rclone's configuration file.
  • File content is transferred directly between the owner's computer and Google Drive. Transient local cache copies exist only while a file is being written and are deleted after the upload completes.
  • No data is sent to any server operated by the owner of this client. This project operates no servers.

5. Sharing and third parties

No data is sold, rented, shared, or disclosed to any third party. There is no advertising, analytics, tracking, or profiling. The only parties involved in a transfer are the owner's computer and Google's own API endpoints.

6. Retention and deletion

Data in Google Drive remains under the owner's control and can be deleted through the Google Drive interface or through the client at any time. Local tokens can be removed by deleting the rclone configuration file. Access can be revoked at any time at myaccount.google.com/permissions.

7. Security

Communication with Google uses HTTPS. The refresh token is kept on the owner's local machine and is not published or shared. The client runs with the minimum practical exposure: a single user, a single machine, and no network services of its own.

8. Children

The client is not directed at children and is not used by anyone other than its owner.

9. Changes

If this policy changes, the updated version will be posted on this page with a new date.

10. Contact

Questions about this policy can be raised through the repository that hosts this page.
